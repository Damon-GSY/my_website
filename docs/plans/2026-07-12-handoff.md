## Architecture

### Files (all in `src/`)
| File | Role |
|------|------|
| `App.tsx` | Single-page entry. Scroll-driven parallax + 6 content waypoints + effects. |
| `landscape/renderer.ts` | Canvas-2D parallax renderer. Draws 4 layers (landscape + depth + light + foreground) into ONE canvas at 1x resolution. 60fps. |
| `landscape/math.ts` | Pure functions: `clamp`, `smooth` (smoothstep), `band` (fade in/out). Unit-tested. |
| `landscape/effects.tsx` | Ported effects (zero-dep, no framer/gsap/lucide): `EncryptedText`, `NumberTicker`, `MagneticButton`, `Signature`, `AgentConsole`, `AgentNetwork`, `Accordion`, `SparklesText`, `useInViewOnce`. |
| `landscape/math.test.ts` | 15 vitest characterization tests (all green). |
| `index.css` | Tailwind v4 (`@import "tailwindcss"`), dark theme `#0a0a0c`, accent `#d97757`, `@keyframes sparkle + shimmer`. |

### Performance
- **Canvas-2D renderer** (not DOM layers) — 1 element composited, 1x backing resolution. Measured: **60fps, p90=17ms, max=18ms** (headed wheel scroll).
- Instant scroll tracking (no lerp) — no reversal overshoot, no input lag.
- All effects (EncryptedText, NumberTicker, AgentConsole, MagneticButton) are **reveal/hover/click triggered** — zero per-frame cost.
- Bundle: **218KB / 68KB gzip** (React-only — no framer-motion, gsap, react-router, or lucide-react in the bundle).

## Known issues / TODO
1. **AgentNetwork** component is built + in effects.tsx but **not currently used** (terminal was preferred). Could be re-added (stacked with terminal, or as a separate section).
2. **Accessibility**: gradient text (`color: transparent` + `background-clip: text`) may not render in high-contrast mode / all screen readers. EncryptedText scramble is confusing for SR. Low-contrast muted text.
3. **Content jargon**: papers/projects use specialist terms (GRPO, multi-turn taxonomy). Could use plain-language impact descriptions for non-specialist visitors.
4. **External links**: papers don't link to arXiv. GitHub/YouTube/Bilibili are footer-only (not highlighted).
5. **Legacy dead code**: `src/components/*`, `src/data/*`, `src/lib/*` are from main's old multi-page site. Not imported by App.tsx. Could be deleted to slim the repo. tsconfig include is narrowed to `src/main.tsx, src/App.tsx, src/landscape, src/vite-env.d.ts` to exclude them from typecheck.
6. **Mobile**: tested at 390px — hero stats wrap 2×2, 2-col grids stack. No horizontal overflow. But comprehensive mobile QA not done (e.g., agent console hidden on mobile via `hidden md:block`; dots nav may need touch-friendly tap targets).
