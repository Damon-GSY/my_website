# Whole-site QA pass, 2026-11-15

Build: `npm run build`, served with `vite preview` (port 4271). Playwright + Chromium. Each route was loaded at 1440x900 and 390x844 in three modes:

- **gl**: WebGL on (SwiftShader), normal motion
- **reduced**: WebGL on, `prefers-reduced-motion: reduce`
- **no-gl**: `--disable-webgl --disable-3d-apis` (only for the WebGL pages: `/`, `/parcel`, `/descent`, `/rollout`, `/d20`, `/lab/night/`, `/lab/paper/`)

For every run the script recorded console errors, page errors, failed requests and horizontal overflow (`scrollWidth - innerWidth`). It also took a screenshot of the first viewport and one at mid-page. All screenshots went into contact sheets and were looked at. Keyboard: on `/` and `/lab`, the first 16 Tab stops all show a 2px solid outline (`:focus-visible`).

Result: no page errors, no failed requests and no horizontal overflow on any route except the concept boards (by design, see below). In no-gl mode the only console output is three.js's own "could not create a WebGL context" message. Every WebGL page then shows a readable static fallback, not a blank page.

## Fixes

1. **Home: the "Studio Lens +" button covered the hero's "Roam to unveil" hint** at both sizes, because both sit bottom-right. The hint is now lifted above the button. `src/pages/home.css:491` and `:500`. Checked at both sizes: section ends no longer overlap the button once the layout has settled. Every section already has at least 67px of bottom padding, and the Contact footer clears it.
2. **`/parcel` static fallback (reduced motion or no WebGL): the fixed header was transparent**, so the work cards scrolled under "Damon Guan / Design studies". In static mode the header now gets the page colour. `src/styles/base.css:126` (`.film.static > .chrome`). This applies to every film-based study in static mode.
3. **`/lab/paper/` on phones: in the Research list, "Multi-turn agent evaluation survey" and "~250 papers" printed on top of each other.** The `grid-area` names from the generic phone row rule still applied inside `.cols`, where the template areas are reset. `public/lab/paper/index.html:70`.
4. **`/lab/parcels/` open view at 1440x900: the "Next parcel" card ran 25px past the fold** (bottom at 925px). The bottom flap now stacks from the top instead of pushing the card to the flap's bottom edge, so the card ends at 802px. `public/lab/parcels/index.html:110`.

Checked, no change needed: on `/lab/agent/` at 390x844, the "reading SupChain-Bench" label now sits below the row's 530 figure without overlapping it. Confirmed by screenshot at `?speed=3`.
